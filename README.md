# Entre NAPs · Periódico Digital do Marista Pio X

Proposta de periódico digital de ciência e tecnologia dos estudantes do Colégio Marista Pio X, com navegação no padrão das redes sociais.

- [`docs/ANALISE.md`](docs/ANALISE.md): análise do pacote *Entre NAPs v4* e proposta de identidade, organização e próximos passos.
- [`previa/`](previa/): prévia funcional e interativa (HTML, CSS e JavaScript, sem dependências). Abra `previa/index.html` por um servidor local, por exemplo `npx serve previa` ou `python3 -m http.server -d previa`.

A prévia guarda curtidas, comentários e envios apenas no navegador de quem testa. Troque o perfil (Estudante, Comitê, Curadoria) na aba Perfil para testar publicação e curadoria.
